# Vessel and Batch Labels

A label has one job: let anyone — including you in eight months — reconstruct what is in the
vessel and where it came from, without consulting anything else. Two fields do most of that work
and are the two most often left off: **subculture number** and **mother plant ID**. Neither can
be reconstructed after the fact, and without them a plant cannot be honestly sold as
true-to-type.

## Vessel label (minimum)

Sized for a small adhesive label or a paint-pen mark:

```
MON-ALB / S2 / II
2026-03-25  MS-BAP10  TC
```

Reading: batch `MON-ALB`, subculture 2, Stage II, transferred 25 March 2026, on medium
`MS-BAP10`, by operator TC.

## Vessel label (full)

Where label space allows:

```
+--------------------------------------+
| MON-ALB-2026-03-A                    |
| Monstera deliciosa 'Albo-Variegata'  |
| Stage II  ·  Subculture 2            |
| Medium MS-BAP10                      |
| Transferred 2026-03-25  ·  TC        |
| Mother MDA-03  ·  Init 2026-01-12    |
+--------------------------------------+
```

## Batch ID convention

```
GENUS-CULTIVAR-YYYY-MM-X
MON-ALB-2026-03-A
```

Where `X` distinguishes lines split from the same parent batch in the same month. Keeping the
initiation date and mother ID attached through every subculture is what makes the lineage
traceable — a batch ID that resets at each transfer loses exactly the information you need.

## Fields and why each earns its space

| Field | Why |
|---|---|
| Batch ID | Links to the culture log |
| Full genotype | Genus, species, cultivar. "Monstera" alone is not a genotype |
| Stage | Determines what the vessel needs next |
| **Subculture number** | Somaclonal variation accumulates with cycles. Unreconstructable if not tracked from the start; the basis of any trueness-to-type claim |
| Medium ID | Links outcomes back to a formulation record |
| Transfer date | Drives the subculture schedule and dates any observation |
| Operator | Contamination clustering by operator is a real, fixable signal |
| **Mother plant ID** | Provenance. Required to re-initiate a line when it ages out, and to substantiate what you are selling |
| Initiation date | Age of the line |

## Practical notes

- **Write on the vessel, not only the closure.** Closures get swapped during transfer and the
  label goes with the wrong plant.
- **Autoclave-resistant marking** — solvent-resistant marker or paint pen. Ordinary labels lift
  in the autoclave and in the high humidity of a culture room.
- **Increment the subculture number at transfer**, as part of the transfer itself. Doing it later
  from memory is how the count silently drifts.
- **Quarantine marking** — mark new establishments distinctly and keep them physically separate
  for 3–4 weeks. Latent endophytes routinely take 2–6 weeks to surface.
- **Colour-code by genotype** if the room holds many lines; it makes misplaced vessels visible
  from across the room.
- **Mark off-type culls before discarding** so the count reaches the log. Off-type rate is the
  honest measure of drift, and it only exists if someone writes the number down.
